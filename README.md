# Hotel Reservation System

A console-based hotel reservation management system developed in Java. The application allows users to register, view, search, and sort hotel reservations.

## Technologies

- Java
- Scanner (user input)
- Arrays
- Object-Oriented Programming (OOP)
- Encapsulation
- Bubble Sort

## Features

- Register up to 10 hotel reservations.
- Store guest names, room types, number of days, and daily rates.
- Calculate the total price of each reservation.
- List all registered reservations.
- Search reservations by partial guest name, ignoring uppercase and lowercase differences.
- Sort reservations by number of days in descending order.
- Validate guest names and room types to prevent empty entries.
- Validate the number of days and daily rate.
- Display a message when the reservation capacity is full or no reservations are registered.

## How to Run

1. Clone or download this repository.
2. Open the project in your preferred Java IDE.
3. Make sure both `Reservation.java` and `HotelReservationSystem.java` are in the same project.
4. Compile and run the `HotelReservationSystem` class.
5. Select an option from the main menu and follow the instructions.
